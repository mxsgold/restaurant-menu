# NOIR — Restaurant Menu

Premium dark restaurant menu built with React and Next.js.

## Features
- Responsive premium dark UI
- Category filtering
- Live dish search
- Dish detail modal
- Mobile-first layout
- Ready for Supabase-backed dynamic menu data

## Run locally
```bash
npm install
npm run dev
```

The current dishes are demo data. The next integration will replace them with Supabase rows and Supabase Storage images managed from the separate `restaurant-admin` app.
